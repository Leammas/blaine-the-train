# Mesocycle 1 — Divca sharpening, build block

**Block focus:** convert current fitness into the Divca 28k/1453m profile.
Two race-specific stimuli per week: fortress stair repeats (Tue, ≤1h) and a
Fruška Gora trail long run (Sat, access ride budgeted). Downhill exposure
grows in small controlled doses (stairs + FG descents) because descent is the
ITB trigger — never more than +10% descent week over week, per coach rules.

**What progresses:** long-run trail time (2:00 → 2:40 on trail), stair-repeat
count (8 → 12), weekly descent meters per targets above.

**What holds:** strength stage 0 (2×/week, no changes before the race), run
volume band 40–48 km (hours cap binds — race specificity beats volume),
Thursday social ride, Sunday easy/medium run. `run_km_targets` count optional
mobility runs when done (core + optional); `descent_m_targets` stay within
the 1.10×-3-week-average gate, re-derived weekly in practice.

**Heat rule of the block:** August/September mornings can exceed 28–30°C by
08:00 — quality and long sessions start 05:30–06:30; by-HR conversion when
≥30°C at session time.

**Exit criteria to meso 2 (taper, 2026-09-14 .. 2026-09-28):** week 3
completed with no ITB symptom above 2/10 and no symptom on descents; last
long run ≥2:30 trail time with sustained descents pain-free. If symptoms
appear: freeze descent progression, keep flat volume, taper unchanged.
